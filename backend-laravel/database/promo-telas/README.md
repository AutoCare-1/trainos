# Telas capturadas pro Reels de divulgação

PNGs reais do app (Playwright, 430x932 @2x), conta de demonstração
`promo@clubemais.dev` / `promo12345` — 8 alunos, 16 treinos, 48 sessões fictícios.

Versionadas de propósito: o Dev Log registra que o backup da sessão anterior
sumiu junto com o scratchpad. 3 MB é barato perto de recapturar.

Servem como os "cards" do fluxo `ugc-website-video`, que exige **pixels reais**
— UI gerada por IA é proibida ali, senão o app do vídeo não é o app.

Boas: `01-alunos`, `02-videos` (filtros Todos 402 / Peito 46…), `05-agenda`,
`06-videos-scroll`, `07-treino`.
Fracas: `03-treino-novo` (sai vazio sem aluno selecionado).

Não usar `/negocio`: mostra R$ 0,00, e ficou combinado não exibir número de
faturamento, que viraria alegação falsa.
